# Sameer Bera - Professional CV & Resume

This repository contains the source code for my professional web CV and printable resume. 

It was built with a focus on modern web design principles, including responsive CSS Grid/Flexbox layouts, glassmorphism aesthetics, and clean semantic HTML5.

## 🌐 Live Preview
You can view the live web CV here: **[https://sameerbera.github.io/cv/](https://sameerbera.github.io/cv/)**

## 📄 Printable Resume
The repository also includes a `resume.html` file that is styled with a print-specific CSS (`resume.css`). You can open it in a browser and save it directly as an A4 PDF for job applications.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Custom Variables, Flexbox, Grid, Animations)
- Google Fonts (Inter, Outfit)
